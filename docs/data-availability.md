# Data Availability

The complete LMTO training and testing datasets for this study are hosted on
Zenodo:

https://zenodo.org/records/19179419

Use the same Zenodo record or final DOI in the manuscript and in this
repository so that readers can move between the paper, data archive, and code
without ambiguity.

Recommended manuscript wording:

```text
The complete LMTO dataset supporting the MLIP fine-tuning described in this
study is openly available on Zenodo at https://zenodo.org/records/19179419.
This repository includes the training and testing datasets.
```

## Repository data

The local `data/` directory contains only compact repository-level test data.
The full raw datasets should remain on Zenodo rather than in git.
